# Wander Notes

Wander Notes is a sample travel blog website created as a beginner web development project for learning and practice.

## About the Project

The website is designed around a travel blog theme, featuring beautiful destinations, travel stories, helpful tips, and an About section.

This project is a **sample model created for learning purposes only**. It is intended to help me understand the fundamentals of web development by building a website from scratch.

## Technologies Used

- HTML5
- CSS3

## Features

- Travel blog themed layout
- About section
- Images of travel destinations
- Custom color scheme and styling
- Footer with navigation links
- Basic layout and positioning using CSS

## Development Approach

This project was built through **manual hard-coding using HTML and CSS** as part of my learning process.

The elements, layouts, colors, spacing, and styling were written manually to practice and understand the fundamentals of front-end development.

The project is still a work in progress, and improvements may be made as I continue learning.

## Purpose

The main goal of this project is to strengthen my understanding of HTML and CSS, improve my layout and styling skills, and gain practical experience by building a website independently.

## Disclaimer

Wander Notes is a practice project and is not intended to represent a fully functional commercial travel blog. Some elements are sample content created for demonstration and learning purposes.
